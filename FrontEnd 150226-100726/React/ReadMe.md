# React Setup with Vite

## Step 1: Install Node.js

- React (and Vite) require Node.js.
- Download and install it from  :-  <https://nodejs.org>

- After installation, check versions:
  - node -v
  - npm -v

________________________________________

## Step 2: Create a React App using Vite

- In your terminal, run:
- npm create vite@latest my-react-app
- my-react-app is your project name — you can choose any name.

________________________________________

## Step 3: Choose Framework and Variant

- After running the above command, Vite will ask:
✔ Select a framework: › React
✔ Select a variant: › JavaScript
- If you prefer TypeScript, select React + TypeScript instead.

________________________________________

## Step 4: Move into the Project Folder

- cd my-react-app

________________________________________

## Step 5: Install Dependencies

- npm install

________________________________________

## Step 6: Start the Development Server

- npm run dev
    After that, you’ll see something like this:
  VITE v5.0  ready in 300 ms
  ➜  Local:   <http://localhost:5173/>
Open this link in your browser:
<http://localhost:5173/> — and your React app will be live!

________________________________________

## Step 7: Folder Structure

- Here’s what your project folder will look like:
my-react-app/
│
├── node_modules/
├── public/
├── src/
│   ├── App.jsx
│   ├── main.jsx
├── index.html
├── package.json
└── vite.config.js
