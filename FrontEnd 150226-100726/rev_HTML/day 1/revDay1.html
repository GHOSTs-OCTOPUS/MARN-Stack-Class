13. Tag sub → For subscripted text or content

The 'sub' tag in HTML is used to define subscripted text, which appears smaller and lower than the surrounding text's baseline. It is primarily used for formatting chemical formulas, mathematical notations, and footnotes, primarily for typographical reasons.

14. Tag sup → For subscripted text or content

17. Tag img → For used to embed an image in a web page

The HTML 'img' tag is used to embed an image in a web page. This is an inline, self-closing tag, meaning it does not have a separate closing tag (e.g.,'/img'). Images are not technically inserted directly into an HTML document; the 'img' tag creates a holding space and links to the image source file, which the browser then fetches and displays.
